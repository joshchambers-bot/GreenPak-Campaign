What GreenPAK Replaces

TodayDiscrete glue logic

  • Separate chips for logic, delays, sequencing, and supervision
  • More placements, more routing, more board area
  • Every design change can mean a new part or a board respin
  • Off-the-shelf parts that anyone can read off your board

With GreenPAKOne configurable chip

  • Logic, timing, analog, and power functions in one package
  • Fewer placements and a smaller footprint
  • Change the circuit in software and re-sample — no new part
  • A custom part number and datasheet for your design

Start with the Problem You're Solving

Replaces: Power Sequencer · Reset IC · Voltage Supervisor

Sequence Power Rails and Supervise Resets

Bring rails up in the right order, hold the processor in reset, and supervise voltages — in one chip instead of several. Some parts add LDOs and load switches.

See Power GreenPAK →
Replaces: Logic Gates · Flip-Flops · Counters · Level Shifter

Replace Glue Logic and Translate Voltage Levels

Swap a row of discrete gates, flip-flops, and counters for one configurable chip, and bridge two independent voltage domains without a separate level shifter.

See Dual Supply GreenPAK →
Replaces: Debounce Circuit · Delay Timer · PWM Generator

Debounce Buttons, Add Delays, and Generate PWM

Clean up noisy inputs, build delays and PWM, drive LEDs, or run a custom state machine — all from the chip's oscillators, counters, and LUTs instead of separate timer and logic parts.

See State Machine GreenPAK →
Replaces: Motor Driver · Control Logic

Drive a Brushed DC Motor, Stepper, or Solenoid

Put a high-voltage H-bridge and the mixed-signal logic that controls it in one chip, instead of a separate motor driver and controller.

See HVPAK →
Replaces: Analog Front End · ADC · Glue Logic

Build a Sensor Interface or Analog Front End

Design your own analog circuit next to configurable logic on the same chip. A low-power option adds a 14-bit SAR ADC for reading sensors.

See AnalogPAK →
Automotive · AEC-Q100 Qualified

Cut Part Count in Automotive Designs

Fold several system functions into one AEC-Q100 qualified IC. Extended-temperature GreenPAK parts run from −40 °C to +125 °C.

See Automotive GreenPAK →

What You Get on the Board

Smaller Footprint

Fewer placements and less routing on the PCB.

Lower BOM Cost

One part under $1 in place of several, with no production programming cost.

Lower Power

Reduced power consumption, suited to battery-powered designs.

Design Security

A unique custom part number and datasheet make your circuit harder to copy.

No Code

A graphical design process — no programming language, no compiler, no software cost.

Fast Changes

Rework the circuit in the GUI and re-sample. Some parts reprogram in-system.
